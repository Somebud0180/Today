# Building the app

The app is made for iOS and iPadOS (With limited support for Mac and Apple Vision). The app can be built using Xcode.

## Prerequisites

- **Xcode:** Version 27.0 or later
- **macOS:** Version 26.4 or later[^1]

## Setup

1. Clone the repository with `gh repo clone Somebud0180/Today` or download it as a ZIP under the code button above.
2. Open `Today.xcodeproj` in Xcode.
3. (Optional) Configure the signing team under **Today > Targets: Today > Signing & Capabilities**.

## Running the app
1. Run the app via the menubar (Product > Run) or the toolbar (the play button).

[^1]: Minimum supported macOS version by Xcode 27
